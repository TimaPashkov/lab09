### Задание 1 **(2)**
*Рассмотрим следующую программу.*
```
d = {'sep': ',' , 'end': '\n'}
l = ['Утопия', 14, 'Вселенная', 25]
print (l, d)
print (*l, d)
print (*l, *d)
print (*l, **d)
```
*Решение*

Что выведет программа:

```
['Утопия', 14, 'Вселенная', 25] {'sep': ',', 'end': '\n'}
Утопия 14 Вселенная 25 {'sep': ',', 'end': '\n'}
Утопия 14 Вселенная 25 sep end
Утопия,14,Вселенная,25
```

Тут вся суть в звёздочках при вызове функции.

1. `print(l, d)`. Без звёздочек в `print` уходят два аргумента: сам список и сам словарь. Они печатаются целиком, со скобками, через пробел.
2. `print(*l, d)`. Одна `*` перед списком «раскрывает» его, и каждый элемент передаётся как отдельный аргумент. Получается 4 элемента списка и словарь целиком. Элементы идут без скобок, а словарь печатается как был.
3. `print(*l, *d)`. Если раскрывать словарь одной `*`, то берутся только его ключи. Поэтому в конце напечатались слова `sep` и `end`.
4. `print(*l, **d)`. Две `**` раскрывают словарь в именованные аргументы, то есть это то же самое, что `print(*l, sep=',', end='\n')`. Значит, элементы печатаются через запятую без пробелов, а в конце ставится перевод строки (он и так стоит по умолчанию).

### Задание 2 **(2)**
*Напишите функцию* **sublist** для решения следующей задачи.*

*На вход функции поступает список или кортеж и набор номеров позиций.
Функция должна составить и вернуть список из элементов, которые
находятся на этих позициях. Примеры работы приводятся ниже. Работа функции должна строго им соответствовать.*

```
>>> lst = [ 'Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
>>> sublist(lst, 0, 2, 5)
['Anna', 'Clara', 'Flora']
>>> sublist (lst)
[]
>>> sublist(lst, 0, 1, 2, 3, 4, 5)
['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
```

*Решение*

```python
def sublist(lst, *positions):
    result = []
    for i in positions:
        result.append(lst[i])
    return result
```

Проверка:

```python
lst = ['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
print(sublist(lst, 0, 2, 5))
print(sublist(lst))
print(sublist(lst, 0, 1, 2, 3, 4, 5))
```

Результат:

```
['Anna', 'Clara', 'Flora']
[]
['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
```

`*positions` собирает все номера позиций, которые передали после списка, в один кортеж. Если номеров нет, кортеж пустой, цикл не выполнится и вернётся пустой список. Работает и с кортежами, например `sublist(('a', 'b', 'c'), 2, 0)` вернёт `['c', 'a']`.

### Задание 3 **(1)**

*Задан список* **lst** *из натуральных чисел*. *Напишите фрагмент
программы, состоящий из одного вызова функции* **max**, *который найдет в этом списке число с максимальным
числом единиц в двоичной записи.* 

*Многоточие надо заменить на лямбда-функцию, использующую фукцию* **bin** *и метод строк* **count**.

*Пример работы приводится ниже.*
```
>>> lst = list(range(6000 ,7000))
>>> ans = max(lst,...)
>>> print(ans)
6143
```

*Решение*

```python
lst = list(range(6000, 7000))
ans = max(lst, key=lambda x: bin(x).count('1'))
print(ans)
```

Результат:

```
6143
```

`bin(x)` переводит число в строку с двоичной записью, например `'0b1011111111111'`. Метод `count('1')` считает в ней единицы. Параметр `key` говорит функции `max`, что сравнивать надо не сами числа, а количество единиц. У числа 6143 их 12, это максимум для диапазона.

### Задание 4 **(2)**

*Запишите фрагмент программы, которая упорядочит список слов
по длине, а при равенстве длины - лексикографически. Сортировка
должна состоять из одного вызова метода* **sort**.

*Пример работы приводится ниже.*

```
>>> lst = ['hello', 'hell', 'bye', 'world', 'bybye']
>>> lst.sort (...)
>>> print (lst)
['bye', 'hell', 'babye', 'hello', 'world']
```

*Решение*

```python
lst = ['hello', 'hell', 'bye', 'world', 'bybye']
lst.sort(key=lambda w: (len(w), w))
print(lst)
```

Результат:

```
['bye', 'hell', 'bybye', 'hello', 'world']
```

В `key` возвращается пара `(длина, слово)`. Python сравнивает пары по очереди: сначала по первому элементу (длине), а если длины равны, то по второму (само слово, то есть по алфавиту).

Примечание: в примере из условия вместо `bybye` написано `babye`, скорее всего опечатка. Если оставить `bybye`, как в исходном списке, то получается результат выше.

### Задание 5 **(2)**

*Напишите программу для решения следующей задачи.*

*В одной строке через запятую записана последовательность слов. Перед
запятой или после нее могут быть пробелы, сами слова пробелов не
содержат. Программа должна вывести в одной строке через запятую
последовательность чисел, равных длине каждого слова. Например,
для ввода*
```
hello   ,   world ,   and ,   goodbye
```
*программа должна вывести*
```
5, 5, 3, 7
```
*Программа должна быть написана с использованием парадигмы функционального программирования, то есть без использования циклов, присваиваний и т.д. Программа может использовать функции* **input**, **print**, **len**, **map** *и методы строк* **split** и **strip**.

*Решение*

```python
print(*map(len, map(str.strip, input().split(','))), sep=', ')
```

Ввод:

```
hello   ,   world ,   and ,   goodbye
```

Вывод:

```
5, 5, 3, 7
```

Идём изнутри наружу:

1. `input().split(',')` читает строку и режет её по запятым. Получаются слова с пробелами по краям.
2. `map(str.strip, ...)` убирает лишние пробелы у каждого слова.
3. `map(len, ...)` заменяет каждое слово его длиной.
4. `print(*..., sep=', ')` печатает все числа в одну строку, разделяя их запятой с пробелом.

### Задание 6 **(2)**

*Запишите генератор в форме функции, который будет создавать
последовательность по следующему правилу.*

* *Если текущее число x в последовательности четное, то следующее число равно x/2.*
* *Иначе следующее число равно 3x + 1.* 

*Последовательность начинается с заданного числа n и заканчивается единицей.*

*Далее приведен пример работы генератора.*
```
>>> print (*gen(7))
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

*Решение*

```python
def gen(n):
    yield n
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        yield n
```

Проверка:

```python
print(*gen(7))
```

```
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

Сначала отдаём само `n`. Потом, пока не дошли до единицы, считаем следующее число по правилу и тоже отдаём его через `yield`. Если `n = 1`, то вернётся только `1`.

### Задание 7 **(2)**

*Напишите генератор, который для заданной последовательности*
**seq** *будет задавать последовательность из каждого второго элемента* **seq**.

'''
def every_other ( seq )
    ...
'''
*Ниже приведены примеры использования генератра.*
```
>>> print (*every_other([10, 20, 30, 40, 50]))
10 30 50
>>> print(*every_other(range(10)))
0 2 4 6 8
>>> print(*every_other(iter(range(10))))
0 2 4 6 8
>>> print(sum(every_other(map(int, input().split()))))
2 5 11 3 8
21
```

*Решение*

```python
def every_other(seq):
    i = 0
    for x in seq:
        if i % 2 == 0:
            yield x
        i += 1
```

Проверка:

```python
print(*every_other([10, 20, 30, 40, 50]))
print(*every_other(range(10)))
print(*every_other(iter(range(10))))
print(sum(every_other(map(int, input().split()))))
```

```
10 30 50
0 2 4 6 8
0 2 4 6 8
21
```

(для последней строки вводил `2 5 11 3 8`)

Переменная `i` считает, какой по счёту элемент мы сейчас обрабатываем. Если номер чётный (0, 2, 4...), то отдаём элемент, иначе пропускаем. Так как используется обычный цикл `for`, функция работает и со списками, и с `range`, и с итераторами.

###  Задание 10 **(1)**
*Какие из указанных функций и методов Python соответствуют определению чистых функций?
В случае отрицательного ответа требуется дать пояснение.*

* **file.readline|** — *чтение строки из файла.*
* **len** — *определение длины строки или количества элементов в контейнере.*
* **list.append** — *добавление в список нового элемента.*
* **sum** — *нахождение суммы.*
* **sorted** — *построение сортированного списка.*
* **list.sort** — *сортировка списка.*
* **random.randint** — *генерация случайного целого числа.*
* *Разворот списка.*
```
def rev(x):
    return x[::-1]
```
* *Выбор нескольких элементов из хвоста списка.*
```
tail_len = 3
def tail(x):
    return x[-tail_len:]
```

*Решение*

Чистая функция всегда возвращает один и тот же результат для одних и тех же аргументов и ничего не меняет вокруг себя (нет побочных эффектов).

| Функция | Чистая? | Пояснение |
|---|---|---|
| `file.readline` | нет | Каждый вызов двигает позицию в файле, поэтому при одинаковом вызове результаты разные. Ещё она зависит от содержимого файла. |
| `len` | да | Только считает длину и ничего не меняет. |
| `list.append` | нет | Меняет сам список (побочный эффект), а возвращает `None`. |
| `sum` | да | Возвращает сумму, исходные данные не меняет. |
| `sorted` | да | Создаёт новый отсортированный список, а старый остаётся как был. |
| `list.sort` | нет | Сортирует список «на месте», то есть меняет исходный список. |
| `random.randint` | нет | При одинаковых аргументах результат разный, ещё и меняется внутреннее состояние генератора случайных чисел. |
| `rev` (разворот списка) | да | `x[::-1]` создаёт новый список, `x` не меняется. |
| `tail` (хвост списка) | нет | Результат зависит от глобальной переменной `tail_len`, а не только от аргумента. Если изменить `tail_len`, то при том же `x` будет другой результат. |

### Задание 1 **(3)**

*Самостоятельно познакомьтесь с понятием декораторов в Python. Приведите примеры использования
функции* **toint** *из задания выше в качестве декоратора.*

*Решение*

Декоратор это функция, которая принимает другую функцию и возвращает её изменённую версию. В Python для этого есть короткая запись: `@имя_декоратора` перед `def`. Запись

```python
@toint
def add(a, b):
    return a + b
```

делает то же самое, что и

```python
def add(a, b):
    return a + b
add = toint(add)
```

Примеры использования `toint` как декоратора:

```python
@toint
def add(a, b):
    return a + b

print(add('2', '3'))       # 5
```

```python
@toint
def total(*nums):
    return sum(nums)

print(total('1', '2', '3', '4'))   # 10
```

### Задание 2 **(3)**
*Напишите фрагмент программы, которая найдет в списке слов слово с максимальной длиной. При равенстве длин
найдет самое первое в лексикографическом порядке.*

*Фрагмент программы должен состоять из одного вызова функции* **min** *или* **max**.

*Решение*

```python
words = ['pear', 'apple', 'banana', 'cherry', 'fig', 'banane']
print(min(words, key=lambda w: (-len(w), w)))
```

```
banana
```

Нужно самое длинное слово, а при равной длине самое первое по алфавиту. Берём `min` и в `key` ставим пару `(-len(w), w)`. Минус перед длиной переворачивает порядок, поэтому самые длинные слова считаются «самыми маленькими». Если длины одинаковые, то `min` выбирает по второму элементу, то есть по алфавиту.
